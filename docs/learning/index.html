Learning series

Six standalone lessons about the internals of kotlin-notion-client. Each one is independently readable, in any order.

  1. 01 — The wire is the contract medium

    Why this library hand-writes KSerializers instead of leaning on @Serializable: Notion’s "type" tag names a sibling key rather than acting as a class discriminator, and a closed sealed hierarchy crashes on every property type Notion ships after your release.

  2. 02 — explicitNulls = false and the sentinel pattern hard

    Why explicitNulls = false silently ate icon.remove() for months while making select(name, null) fail with an HTTP 400, and how a write-only sentinel value plus a choice between two CompositeEncoder overloads fixes both.

  3. 03 — Type-safe builders, and why five authors got the DSL wrong easy–medium

    How Builder.() -> Unit powers every request DSL in the library, why single-value builders carry a val and a same-named fun, and what twenty snippets that never compiled say about designing affordances rather than blaming users.

  4. 04 — Coroutine primitives in anger: the rate limiter hard

    A continuous-refill token bucket, a Mutex deliberately held across its delay, a Ktor Send hook that paces retries too, and the injected clock that makes all of it testable in virtual time.

  5. 05 — Pagination as a cold Flow medium

    How ten lines of flow { } turn a Notion cursor chain into a cold stream — what coldness actually buys, why collectAll is usually still the right call, and where the chain stops working at 10,000 rows.

  6. 06 — Being a library, not an application medium

    What changes when the compiler can no longer see your callers: sealed-variant source breaks, internal as a real tool, binary versus source compatibility, and what a 0.x version number actually promises.

Every code excerpt in these lessons is quoted verbatim from the file and line range cited above it, and every behavioural claim is traced to code, an ADR under docs/adr/, a journal/ entry, or CHANGELOG.md. The brief that specified the series, and the findings the lessons turned up along the way, are in docs/learning/HANDOFF.md.
